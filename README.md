# Portfolio — scrapbook

Полный сайт по ТЗ:
loader → hero → selected work → CADENCE (featured, интерактивный) → about + skills → contact + footer
+ собака-пасхалка + звук (♫ OFF/ON, эмбиент, тихие UI-звуки)

    npm install
    npm run dev

## Что настроить под себя
- `src/content/projects.ts`  тексты, теги, ссылки, скриншоты проектов
- `src/content/photos.ts`    все фото сайта — путь из public/images
- `src/content/skills.ts`    навыки
- `src/content/contact.ts`   контакты (пустые ссылки видны только в dev)

## Звук (src/lib/sound/engine.ts)
Весь звук синтезируется через Web Audio API — файлов нет. Ничего не звучит,
пока человек сам не нажмёт ♫ в правом нижнем углу (это и требование ТЗ, и
ограничение браузеров на автовоспроизведение). После включения:
  - тихий эмбиент (два детунированных тона + редкие «капли» мелодии)
  - hover/click по ссылкам и кнопкам
  - открытие/закрытие карточки проекта
  - переход в новую секцию (один раз за визит)
  - лёгкая трещотка при перетаскивании колеса Cadence

## Cadence (src/components/cadence/)
Показательный проект: колесо на чёрном листе с тахометром.
  - скролл раскручивает колесо (секция закреплена на время прокрутки)
  - мышь слегка наклоняет и сдвигает лист
  - колесо можно раскрутить рукой (drag) — дальше крутится по инерции
  - RPM, стрелка тахометра и «кардиограмма» реагируют на скорость

## Собака (src/components/dog/RoamingDog.tsx)
Сама выходит раз в 25–60 с (первый раз через ~10 с после загрузки), гуляет по
низу экрана, смотрит на курсор, её можно погладить.
Проверить сразу: в консоли браузера — window.dispatchEvent(new Event('dog:spawn'))
